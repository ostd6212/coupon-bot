# coupon-bot

Telegram-бот для паперових купонів Carrefour. Надсилаєш фото купона, Claude (vision) розпізнає назву, умови, дати й штрихкод, бот зберігає купон разом з оригінальним фото (на касі скануєш штрихкод) і нагадує вчасно, щоб купони не згорали.

Окремий сервіс: власна папка, токен, база й користувач. З ботом для вчителів (`school-notification`) нічого спільного.

## Як це працює

1. Фото (одне, кілька або альбом) йде в Claude API, у відповідь строгий JSON зі списком купонів. Дати з іспанських форматів (`05-10-2026`, `VÁLIDO EL DÍA 23 Y 24 DE OCTUBRE`, `HASTA EL 31 DE OCTUBRE`) розбираються за правилами з промпту; дата друку чека не береться до уваги. Якщо модель пропустила дату, бот пробує розібрати її сам з розпізнаного тексту.
2. Бот одразу зберігає купон і відповідає українською підсумком. Підтверджувати нічого не треба; кнопки **Виправити дату / Видалити** потрібні лише якщо щось прочитано не так. Дубль (той самий штрихкод або назва з тими самими датами) не додається.
3. Щодня о `REMINDER_HOUR` (Europe/Madrid) бот надсилає фото купона з підписом і кнопками **Використав / Видалити**:
   - у день початку дії (якщо купон додано раніше);
   - за 3 дні до кінця, за 1 день, в останній день;
   - для купонів «кінець у неділю, а якщо магазин зачинений, то в суботу» окреме суботнє попередження замість «завтра останній день»;
   - для коротких акцій на 1–2 дні (як GRATIS на 23–24): ввечері напередодні о 19:00 і вранці першого дня.
4. О 00:00 купони з минулою датою стають `expired`.

Купони спільні для всіх з `ALLOWED_USER_IDS`: нагадування приходять усім, «Використав» гасить купон для всіх. Повідомлення від інших користувачів ігноруються (їх id пишеться в лог).

## Команди

| Команда | Що робить |
|---|---|
| `/start`, `/help` | інструкція |
| `/active` | купони, що діють зараз, найтерміновіші зверху, з кнопками «📷 фото» |
| `/upcoming` | ще не почали діяти |
| `/all` | усі активні й майбутні |
| `/shop` | «я в магазині»: альбом із фото всіх чинних купонів і підказка, що спрацює від якої суми |

## Змінні (.env)

Дивись `.env.example`. Обов'язкові: `TELEGRAM_BOT_TOKEN` (новий бот від @BotFather), `ANTHROPIC_API_KEY`, `ALLOWED_USER_IDS`. Решта має значення за замовчуванням: `CLAUDE_MODEL=claude-haiku-5-5` (якщо погано читає, постав `claude-sonnet-5-5`), `TZ=Europe/Madrid`, `REMINDER_HOUR=9`.

Дані лежать у `data/`: `coupons.db`, `photos/`, `logs/bot.log`. Це треба бекапити (особливо `photos/`).

## Розгортання на VPS (Ubuntu)

З Mac скопіюй проєкт (без секретів у git):

```bash
rsync -av --exclude .git --exclude .venv --exclude __pycache__ --exclude .DS_Store --exclude data ./ root@IP:/opt/coupon-bot/
```

На сервері:

```bash
cd /opt/coupon-bot && bash deploy/setup_server.sh   # venv, користувач couponbot, служба coupon-bot (не стартує)
nano /opt/coupon-bot/.env                           # токен, ключ, user id
sudo -u couponbot /opt/coupon-bot/.venv/bin/python -m pytest -q
systemctl start coupon-bot
```

Скрипт нічого не змінює в інших службах (ні firewall, ні таймзону, ні школьного бота).

## Щоденне керування

```bash
systemctl status coupon-bot        # стан
systemctl restart coupon-bot       # перезапуск
journalctl -u coupon-bot -f        # логи в журналі
tail -f /opt/coupon-bot/data/logs/bot.log   # логи у файлі (ротація 5×1 МБ)
```

Служба стартує сама після перезавантаження сервера й перезапускається за 5 с після збою. Помилки Claude API (SDK робить 3 повтори) чи Telegram не валять бота; перезапуск не дублює нагадування (таблиця `reminders_sent`), а пропущені за час простою ранкові нагадування бот надсилає через 15 с після старту.

## Оновлення

Одноразово на сервері: ключ тільки для читання.

```bash
ssh-keygen -t ed25519 -f /root/.ssh/coupon_deploy_key -N ""
cat /root/.ssh/coupon_deploy_key.pub    # додай у GitHub: репозиторій → Settings → Deploy keys (без права запису)
cd /opt/coupon-bot
git init -q -b main && git remote add origin git@github.com:ostd6212/coupon-bot.git
git config core.sshCommand "ssh -i /root/.ssh/coupon_deploy_key -o IdentitiesOnly=yes"
git fetch origin main && git reset --hard FETCH_HEAD
```

Далі оновлення однією командою: `bash /opt/coupon-bot/deploy/update.sh`. `.env` і `data/` не чіпаються.

## Розробка й перевірка

```bash
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
```

Тести не ходять в мережу. Вони перевіряють: розбір дат на чотирьох прикладах із ТЗ (ChequeAhorro, 5 EUR DTO, GRATIS Lindt, ACUMULA 10%), ігнорування дати друку чека, нормалізацію відповіді моделі (через підставного клієнта), логіку нагадувань (3/1/0 днів, субота, короткі акції, початок), дедуплікацію, `expired`, відправку нагадувань без дублів після перезапуску.

Перевірка на реальних фото без Telegram:

```bash
set -a; . ./.env; set +a
.venv/bin/python scripts/try_recognize.py photo1.jpg photo2.jpg
```

## Вартість розпізнавання (оцінка)

Одне фото ≈ 2–3 тис. вхідних токенів (зображення + промпт) і ≈ 0,5 тис. вихідних. На `claude-haiku-5-5` ($0,10 / $0,50 за млн токенів) це приблизно **$0,0005–0,001 за фото**, тобто ~1000 фото на $1. На `claude-sonnet-5-5` ($2 / $10) близько **$0,01 за фото**. Точні цифри покаже `usage` у відповіді API або сторінка Usage в console.anthropic.com.
